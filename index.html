Segment editing help

Press N to add points to the selected segment. Split at an interior anchor to label parts of this path. Reorder segments with the up/down buttons; each starts at the previous segment's endpoint, keeping the auto's starting pose fixed. Select an anchor on the field or in the table to move it to another segment; it appends with its control points. Export creates one Java class for the selected path only. Removing a label keeps its points in the neighboring segment.
